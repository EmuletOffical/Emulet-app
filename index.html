Emulet

Add .gb, .gbc or .zip files (or drop them anywhere). Each game’s name is read from its cartridge header, and a cover is captured from the game itself. Everything is stored on this device.

Supported games

“Supported” means Emulet emulates the cartridge’s hardware. It is not a promise that every game runs perfectly, and not every game has been tested.

Systems

  • Game Boy (original) games
  • Game Boy Color games, in color mode
  • Game Boy Advance games, in an early, experimental stage; sound is new and may have glitches

Cartridge types

  • Plain ROM cartridges
  • MBC1, MBC2, MBC3 and MBC5 cartridges, including ones with battery saves
  • Real-time clock for MBC3 games, based on your device’s clock
  • Rumble cartridges run, but there is no vibration
  • Not supported: MBC6, MBC7, HuC3, Pocket Camera and TAMA5 cartridges. HuC1 and multi-game compilation cartridges might run but aren’t tested.

Reported working

  • Pokémon Red Version (boots and plays)

Games Emulet recognizes by name

These show their full names in your library. Any other game with supported hardware can still be added; it appears under its header title, which you can rename.

    Compatibility is a work in progress. If a game doesn’t run correctly, it may be a bug in Emulet.

    Settings

    Speed

    Fast-forwards the game. Sound (where available) may get choppy above 1×.

    Graphics

    Game Boy screen color

    Only affects original Game Boy games. Game Boy Color and Game Boy Advance games use the colors built into the game.

    Save states

    Each slot stores a full snapshot of this game at that moment. Loading a slot replaces what\u2019s happening right now \u2014 it doesn\u2019t erase your regular in-game save.
